## Описание проекта

Данный проект создан для выполнения практических работ по программированию.

### Необходимые условия

Для работы с проектом необходимы:
- Windows
- Visual Studio
- .NET

## Установка

1. Скачать репозиторий.
2. Открыть проект в Visual Studio.
3. Запустить программу.
